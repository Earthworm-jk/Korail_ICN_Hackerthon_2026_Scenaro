# SCENARO 본선 발표 — World Storyboard v0.5

v0.4의 공간 구조를 유지하면서 Phase 2 실제 콘텐츠를 넣은 버전이다. **Scene은 페이지가 아니라 World state**다.

## 01. Hook — 화면 속 장면을 직접 가보고 싶다

**화면**
- `김고은 / 도깨비 / 미스터 션샤인` 예시 카드가 순차 등장
- 오른쪽 한국 지도는 흐리게 존재

**메시지**
> 화면 속 장면을, 직접 가보고 싶었습니다.

**의도**
- 시장 숫자가 아니라 K-콘텐츠 팬의 여행 욕구에서 출발한다.
- 실제 예시 이름을 쓰되 최종 E2E와는 별개다.

## 02. Pull-out — 좋아한 장면은 한 도시에 있지 않다

**화면**
- 첫 큰 camera pull-out
- 한국 지도와 지역 점들이 살아남
- 하단에 72%, 79.3% 근거 카드가 짧게 등장

**메시지**
> 좋아한 장면들은 한 도시 안에 있지 않았습니다.

숫자는 Opportunity를 증명하지만 화면의 주인공은 지도다.

## 03. Problem — 시간표는 서로 맞춰주지 않는다

**화면**
- 지도 유지
- 항공 → 철도 → 관광 카드 순차 등장
- `지도 → 열차 → 운영시간 → 다시 지도` 검색 루프

**메시지**
> 하지만 비행기와 열차, 운영시간은 서로 기다려주지 않습니다.

**발표자 연결**
- 제출 기획서의 일본 성 테마 여행 경험을 한두 문장으로만 사용한다.

## 04. User Evidence — 다시 보고, 다시 맞추고, 포기

**화면**
- 같은 지도 유지
- 현재 중간집계: 22/26, 14명, 11명, 13명
- 익명 자유응답 1개

**메시지**
> 일정이 바뀌면, 다시 보고, 다시 맞추고, 때로는 포기했습니다.

**주의**
- 변경 이유를 항공편으로 해석하지 않는다.
- 최종 발표 전 최신 CSV로 숫자 교체.

## 05. SCENARO Reveal — 추천보다 조율

**화면**
- 지도 유지
- product preview 등장
- 서비스 정의와 흐름 overlay

**메시지**
> 가고 싶은 곳은 사용자가 정하고, 갈 수 있는 여행은 씬나로가 맞춥니다.

Flow:
`배우·작품 복수 선택 → 검증된 장소 → 항공·철도 안에 배치 ↻ 바꾸면 전체 재조율`

## 06. Product Push-in

Golden v0.4 계약 유지. preview와 실제 product viewport의 최종 bounds는 `320,180,1280×720`로 동일.

## 07. E2E Demo

Phase 3 슬롯. 실제 앱 진입 후 종료까지 camera 이동 없음.

## 08. 방금 본 결과는 어디서 왔나

**같은 E2E 마지막 화면 위**
- 항공: 언제부터 언제까지 여행할 수 있는지
- 철도: 그 시간에 실제 이동할 수 있는지
- 콘텐츠: 왜 이 장소를 가고 싶은지
- 관광: 도착했을 때 실제 방문 가능한지

AI는 작은 ribbon 한 줄:
> 배우·작품의 맥락을 연결하고, 바뀐 결과를 사용자 언어로 설명합니다.

## 09. 구현 증거

같은 제품 화면 하단 proof strip. 숫자는 Phase 3 동결 뒤 입력.

## 10. Pull-out — Rail × Air 가치

제품이 축소·소멸하고 지도 경로가 드러난다.
- 여행자: 내 취향을 유지한 채 다시 검색하지 않는 여행
- 인천공항: 입국 이후를 지역 여행으로 연결
- 코레일: 콘텐츠 관심을 실제 철도 이동으로
- 지역관광: 촬영지 방문을 체류·체험으로 연결

## 11. Adoption & Expansion

같은 지도 유지.
> 지금은 일부 권역. 구조는 전국으로 확장됩니다.

`독립 MVP·일부 KTX 권역 → 공항·철도 서비스 진입점 연계 → 전국 철도망·더 넓은 K-콘텐츠`
