# 전체 촬영지 카탈로그

## 목적과 경계

`data/filming-catalog.json`은 배우·작품 검색용 전체 촬영지 카탈로그다. 일정 엔진이 직접
읽는 `data/places.json`의 14개 검증 시드를 대체하지 않는다. 전체 카탈로그의 장소가 실제
일정 후보가 되려면 왕복 시간표, 운영시간, 체류시간과 최신 지도 접근 시간을 추가 검증해
플래너 시드로 승격해야 한다.

2026-08-10 기준으로 대표 배우 5명·작품 10편의 작품–장소 관계 230개와 물리 장소
210곳을 수록했다. 관계 기준 218개는 확정, 12개는 방문 전 재확인이 필요한 조건부다.

## 포함 정책

- 원천: 한국문화정보원 미디어콘텐츠 영상 촬영지 데이터
- 1차 접근성: 원천 좌표에서 지원 역까지 OSRM 차량 경로 60분 이하
- 학교: 외부인 출입 민감도를 고려해 전부 제외
- 작품 속 개인 주택으로 특정된 장소: 사생활·출입 문제를 고려해 제외
- 폐업 또는 현재 상태를 확인하기 어려운 장소: 제외
- 아난티 클럽 서울: 골프클럽으로 명시하고 회원·예약·숙박 및 외관 방문 조건을 사용자가
  확인하도록 `conditional`로 유지
- 50분 이상 경계 장소와 운영 변동 가능 장소: `conditional`과 `visitNote`로 표시

OSRM 값은 대량 선별용 추정치다. 일정에 넣기 전에는 카카오맵 등 최신 지도와 실제 출입·운영
조건을 다시 확인해야 한다. 현재 영문 장소명·장면 설명은 한국어 fallback이며
`translationStatus: "ko_fallback"`으로 명시한다.

## 배우·작품 선택 규칙

- 작품 검색: 검토된 해당 작품–장소 관계 전체
- 배우 검색: 원천 장면 설명에 배우명 또는 검토된 배역명이 있어 장면 등장이 확정된 관계만
- 배우 + 작품 복합 검색: 두 집합의 합집합, 같은 물리 장소는 한 번만 표시

이는 `lib/selection-candidates.ts`의 #51 엄격 후보 규칙과 같다. 배우가 작품에 출연했다는
사실만으로 그 작품의 모든 촬영지를 배우 검색 결과에 넣지 않는다.

대표 배우는 김고은·박보검·공유·이민호·김태리다. 김태리 확장을 위해 《미스터 션샤인》과
《스물다섯 스물하나》를 추가했다. 두 작품의 원천 37개 관계 중 학교 4개, 개인 주택 2개,
지원 역 차량 60분 초과 4개를 제외한 27개 관계를 수록했다.

## 재생성

정책 파일과 검토 스냅샷을 수정한 뒤 다음을 실행한다.

```bash
python3 scripts/build_filming_catalog.py
pnpm test -- lib/__tests__/filming-catalog.test.ts
```
