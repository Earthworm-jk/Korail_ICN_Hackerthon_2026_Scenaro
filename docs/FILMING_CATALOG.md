# 전체 촬영지 카탈로그

## 목적과 경계

`data/filming-catalog.json`은 배우·작품 검색용 전체 촬영지 카탈로그다. 일정 엔진이 직접
읽는 `data/places.json`의 14개 검증 시드를 대체하지 않는다. 전체 카탈로그의 장소가 실제
일정 후보가 되려면 왕복 시간표, 운영시간, 체류시간과 최신 지도 접근 시간을 추가 검증해
플래너 시드로 승격해야 한다.

2026-08-10 기준으로 대표 배우 5명·작품 10편의 작품–장소 관계 230개와 물리 장소
210곳을 수록했다. 장소 상태를 관계에 투영하면 218개는 일반, 12개는 방문 전 재확인이
필요한 조건부다. 이는 배우 등장 검증 등급이 아니다.

## 포함 정책

- 원천: 한국문화정보원 미디어콘텐츠 영상 촬영지 데이터
- 1차 접근성: 원천 좌표에서 지원 역까지 OSRM 차량 경로 60분 이하
- 학교: 외부인 출입 민감도를 고려해 전부 제외
- 작품 속 개인 주택으로 특정된 장소: 사생활·출입 문제를 고려해 제외
- 폐업 또는 현재 상태를 확인하기 어려운 장소: 제외
- 아난티 클럽 서울: 골프클럽으로 명시하고 회원·예약·숙박 및 외관 방문 조건을 사용자가
  확인하도록 `conditional`로 유지
- 50분 이상 경계 장소와 운영 변동 가능 장소: `conditional`과 `visitNote`로 표시

OSRM 값은 대량 선별용 추정치다. 각 장소의 `accessEstimate`에
`method: "osrm_screening"`과 `recheckRequired: true`를 기록한다. 일정에 넣기 전에는 카카오맵
등 최신 지도와 실제 출입·운영 조건을 다시 확인해야 한다.

현재 영문 장소명·장면 설명은 한국어 fallback이며 `translationStatus: "ko_fallback"`으로
명시한다. 영어 화면에 연결할 때는 `englishDisplayPolicy: "hide_ko_fallback"`에 따라 번역 전
항목을 숨겨 한국어 원문이 영어 UI에 노출되지 않게 한다.

## 카탈로그 배우·작품 후보 규칙

- 작품 검색: `catalogReviewStatus: "source_transcribed"`인 원천 전사·선별 관계 전체
- 배우 검색: 원천 장면 설명에 배우명 또는 정책의 배역 토큰이 일치한 관계
- 배우 + 작품 복합 검색: 두 집합의 합집합, 같은 물리 장소는 한 번만 표시

`actorPresenceMatches`는 `sourceRowId`·원천 스냅샷 경로·`excerpt`·실제 매칭 토큰을 보존하는
`source_text_match` 후보다. #92의 A/B 검증 등급이나 사람 검토 완료를 뜻하지 않으며
`actorPresenceVerification`·`reviewed` 필드를 사용하지 않는다. 플래너 또는 검증 완료 검색
결과로 승격하려면 #92의 공식 출처 1개(A) 또는 독립 편집 출처 2개(B) 계약을 별도로 통과해야
한다. 배우가 작품에 출연했다는 사실만으로 작품 전체 장소를 배우 후보로 만들지는 않는다.

대표 배우는 김고은·박보검·공유·이민호·김태리다. 김태리 확장을 위해 《미스터 션샤인》과
《스물다섯 스물하나》를 추가했다. 두 작품의 원천 37개 관계 중 학교 4개, 개인 주택 2개,
지원 역 차량 60분 초과 4개를 제외한 27개 관계를 수록했다.

`nearestStationName`은 현재 접근성 선별 결과를 설명하는 표시 문자열일 뿐 조인 키가 아니다.
`nearestStationReference: "display_name_only_not_join_key"`로 이를 명시한다. 플래너 승격 전에는
별도 역 레지스트리의 안정 ID로 매핑하고 왕복 시간표를 검증해야 한다.

## 재생성

정책 파일과 검토 스냅샷을 수정한 뒤 다음을 실행한다.

```bash
python3 scripts/build_filming_catalog.py
pnpm test -- lib/__tests__/filming-catalog.test.ts
```
