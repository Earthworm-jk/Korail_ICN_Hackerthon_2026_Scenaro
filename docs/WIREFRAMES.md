# 씬나로 화면 와이어프레임 v0.1

> PRD §7 흐름 기준. 시각 디자인이 아니라 **정보 배치와 상태의 계약**이다.
> 각 화면에 REQ ID를 달아 정의서와 대조 리뷰할 수 있게 한다. 모든 문구는 lib/i18n 키로만(#4).

## 흐름

```
S1 항공편·출발가능시점 → S2 배우/작품 검색 → S3 후보 목록 → S4 여행 조건
→ S5 일정 결과 ⇄ S6 편집·재계산(같은 화면 내 패널) / SE 실패·예외 상태
```

화면 수를 줄이기 위해 정의서의 화면 2·3(항공편/출발가능시점)은 S1으로, 화면 8·9(결과/편집)는
S5·S6 한 쌍으로 합친다. 반응형 웹 — 좁은 화면에서는 세로 스택.

## S1 항공편 입력 (REQ-SRCH-001·002)

```
+--------------------------------------------------+
| 씬나로 SCENARO          Your scenario, your route|
|                                                  |
| 입국편  [날짜][시각] 또는 [편명 검색 → 자동입력]  |
|         (편명 검색 시: live/snapshot 출처 표시)   |
| 출국편  [날짜][시각]                              |
|                                                  |
| 공항 출발 가능시점                                |
|  ( ) 착륙 후 90분  (•) 착륙 후 120분  ( ) 직접 [ ]|
|                                                  |
|                         [ 다음: 취향 선택 → ]     |
+--------------------------------------------------+
```
- 두 시각 없이는 다음 버튼 비활성.

## S2 배우/작품 검색 (REQ-SRCH-003·004·005)

```
+--------------------------------------------------+
| [ 배우로 찾기 | 작품으로 찾기 ]   ← 탭            |
| 검색 [ 김고은            ] 🔍                     |
|                                                  |
| 결과                                              |
|  ▸ 김고은 — 출연작 4편                            |
|     [도깨비] [유미의 세포들] [작은 아씨들] [더 킹] |
|     (복수 선택 가능, 선택 시 촬영지 수 미리보기)   |
+--------------------------------------------------+
```
- 결과 0건: SE-1 (빈 화면 금지, 대안 제시).

## S3 촬영지 후보 목록 (REQ-SRCH-006·007·009, REQ-DATA-002)

```
+--------------------------------------------------+
| 정렬 [ 콘텐츠 관련성 ▾ | 공식정보 등록 ]  ← 토글  |
|                                                  |
| □ 영진해변      도깨비        강릉역 · 접근25분*  |
|    검증: 원본확인 · 출처 1  [필수로 지정]         |
| □ 월정사        도깨비        진부역 · 40분*      |
| □ 오크밸리      작은 아씨들   만종역 · 30분*      |
| ⚠ 죽림동성당    유미의 세포들 춘천역(ITX)         |
|    [방문 가능성 직접 확인 필요]  ← #5 배지        |
|                    * 접근시간 추정(이동수단 미포함)|
+--------------------------------------------------+
```
- 관련성 정렬 동점 시 2차 키 officialSourceCount. 배지 2종(API_SPEC의 PlaceCandidate.badge와 1:1): 직접 확인 필요=CONSERVATIVE_BUFFER_MISMATCH / 운영시간 확인 필요=UNVERIFIED_HOURS.
- 항목 탭 → 상세(관계 근거·출처·운영시간·검증일, REQ-SRCH-009).

## S4 여행 조건 (REQ-ITIN-001·002)

```
+--------------------------------------------------+

| 하루 여유시간      [ 120분 ▾ ]   (일반 여유)      |

|                                                  |
| 적용될 제약 요약: 입국 8/12 10:00 · 출국 8/14 18:00|
| · 출국 안전 버퍼 120분(고정)                      |
|                         [ 일정 만들기 → ]         |
+--------------------------------------------------+
```

## S5 일정 결과 (REQ-ITIN-003·004·005·008)

```
+--------------------------------------------------+
| 8/12 (수)                                         |
|  10:00 인천공항 도착 → 출발 가능 12:00            |
|  🚄 KTX 801  서울역 13:01 → 강릉역 14:59          |
|  15:30* 영진해변 (60분)  * 역-장소 접근 25분 추정  |
| (접근시간은 이동수단 미포함 추정치)  8/13 (목) ...  |
| 8/14 (금)  🚄 복귀편 · 공항 도착 15:40             |
|            출국 18:00 (여유 2시간 20분 ✓)          |
|--------------------------------------------------|
| 왜 이 일정인가요? ▾  (comparisonKeys 표시)         |
| 제외된 후보 (2) ▾   ← 사유 코드별 문구 + 다음 행동 |
+--------------------------------------------------+
```

## S6 편집 패널 (REQ-EDIT-001..006) — S5와 같은 화면

```
| [영진해변] 제외 | [월정사] 방문일 8/13 고정 ▾      |
| 항공편 변경: 도착 [10:00 → 12:00]                 |
|                                                  |
| 재계산됨 ✓  총 이동시간 +35분  ← 전후 비교(diff)   |
```
- 재계산 성공 시에만 일정 교체. 실패 시 SE-4.

## SE 실패·예외 상태 (PRD 9.2 — 7종 전부 설계)

| # | 상태 | 화면 계약 |
|---|---|---|
| SE-1 | 검색 결과 없음 | 사유 + 대안 배우·작품 목록 (REQ-SRCH-008) |
| SE-2 | 검증 촬영지 없음 | 사유 + 다른 작품 제안 |
| SE-3 | 운영시간 미확인 | 후보에 배지 유지, 자동 일정 제외 안내 |
| SE-4 | 조건 만족 일정 없음 / 재계산 실패 | **기존 일정 유지** + 사유 코드 문구 + 바꿀 수 있는 조건 버튼 |
| SE-5 | 항공 API 실패 | 스냅샷 전환 알림(source: snapshot), 흐름 계속 |
| SE-6 | 네트워크 단절 | 전 기능 스냅샷 모드 — 배너 1줄, 데모 계속 (NFR-DEMO-001) |
| SE-7 | 데모 리셋 | 초기 상태 복원 버튼(개발용 진입점, NFR-DEMO-002) |
