# 데모 시드 출처와 한계

데모 기준일은 2026-08-12~14(KST)다. 이 문서는 `data/*.json`의 숫자를 실제값처럼
과장하지 않도록 원천과 확인 수준을 기록한다.

## 촬영지

- 작품·촬영지 연결의 1차 원천: 한국문화정보원 촬영지 데이터
  - 공공데이터포털: https://www.data.go.kr/data/15111405/fileData.do
  - 로컬 원본: `data/raw/filming_locations_20260807.csv`
  - 내려받은 날: 2026-08-07
- 대표 배우·작품·14곳 범위: GitHub 이슈 #1 최종 결정
- 장소별 `openingHours.source`가 최신 공식 페이지를 가리키는 경우만 해당 페이지와
  원천 CSV를 교차 확인했다.
- 호텔·리조트·종교시설처럼 공개된 시간이 일반 방문 가능 시간을 뜻한다고 단정할 수 없는
  장소는 `unverified`로 두었다. 이 장소는 후보 화면에는 노출할 수 있지만 자동 일정에서는 제외한다.
- 영문 장소명은 데모 검색·표시용 수동 번역이다. 정식 영문 상호가 확인되는 장소는 구현 중
  공식 표기로 다시 대조한다.

## 역에서 촬영지까지

- `accessEstimate`는 이슈 #1의 연결 역을 기준으로 잡은 **보수적인 대표 추정값**이다.
- 실시간 교통, 택시·버스 선택, 교통 정체를 반영하지 않는다.
- 엔진은 명세대로 `역 → 장소 → 역`에 같은 값을 적용하고, 별도의 보수 버퍼를 더한다.
- UI에는 반드시 `추정`으로 표시한다.

## 철도

- KTX 서울↔강릉 구간: 2026-08-05에 수집한 로컬 `runplan_cache.json`의
  2026-08-12·14 계획시각 중 데모에 필요한 선택지를 이식했다.
- 공항철도 직통열차: 공항철도 공식 평일 시간표를 2026-08-08에 확인해
  인천공항1터미널↔서울역 43분 구간을 이식했다.
  - https://www.arex.or.kr/express/info.do?device=Normal&langCd=en_US&menuNo=MN201503300000000002
- `trainNo`가 `AREX-`로 시작하는 값은 공식 편명 대신 스냅샷 내 고유 식별자로 붙인 값이다.
- 진부(오대산)·만종·춘천·나주 구간의 검증 시간표는 아직 추가 전이다. 해당 역의 촬영지는
  장소 후보 데이터에는 포함되지만, 시간표가 들어오기 전까지 엔진이 방문 가능 일정으로
  확정하면 안 된다.

## 항공

- `SAMPLE-ARRIVAL-001`과 `SAMPLE-DEPARTURE-001`은 회귀 테스트용 고정 입력이다.
- 실서비스의 실제 항공편 조회 결과가 아니며, 실호출 실패 시 폴백하는 데모 스냅샷이다.
