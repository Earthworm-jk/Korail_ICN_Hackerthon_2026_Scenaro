# 데모 시드 출처와 한계

데모 기준일은 2026-08-12~18(KST)다. 시연 기본값은 2026-08-16~18이고, 08-12~14는 실시드 회귀 테스트가 참조하므로 함께 수록한다. 두 창 사이를 비우면 열차 공백이 심야 판정 파생을 뒤틀어서 날짜는 연속으로 채운다. 이 문서는 `data/*.json`의 값을 실제보다
정확한 값처럼 보이지 않도록 원천, 검증 수준, 사용 범위를 기록한다.

## 데이터 사용 원칙

- 관광공사·공공데이터·지도 정보는 후보 발견용이다. 서로 충돌할 때 임의로 하나를
  정답으로 채택하지 않는다.
- 공식 근거로 일반 방문 가능시간을 확인한 경우에만 `hours` 또는 `always_open`을 쓴다.
- `unverified`는 **폐업·철거·방문 불가 확정이 아니다.** 영업시간이나 내부 입장 가능시간을
  확인하지 못했다는 뜻이다.
- 카페·호텔·리조트·성당처럼 휴무일에도 공공도로에서 촬영지를 볼 수 있는 장소는
  검색·일정 후보에서 유지한다. 운영시간은 가능한 경우 그 안에 우선 배치하고, 시간 밖이거나
  미확인이면 내부 이용이 어려울 수 있다는 경고를 표시한다.
- 사용자가 현장에서 사진만 찍을지, 내부 관람·식사·유료 체험을 할지는 서비스가 모델링하지
  않는다. `visitType`·`visitMode` 같은 별도 방문 형태를 추가하지 않는다.
- 현재 엔진은 `unverified`를 자동 일정에서 제외하므로 위 정책과 맞지 않는다. 후속 엔진 변경
  전까지 `unverified`를 거짓 운영시간으로 바꾸지 않으며, 철거·접근 불가만 후보에서 제외한다.

### #51 별칭·주소·좌표·작품 관계 검토

- `work-place-relations.json`의 42개 관계는 위 한국문화정보원 원천 CSV에서 작품명과
  장소명이 일치하는 행을 사용한다. 기존 19건은 수동 대조했고, 추가 23건은
  카탈로그 조인·접근·역·시간표 게이트를 결정적으로 재생성한다. `episodeLabel`은 원천 설명에
  회차가 명시된 경우에만 기록했고, 그 외에는 추측하지 않고 생략했다.
- `sceneNote`는 원천의 장면 설명을 짧게 요약한 값이며 운영시간·방문 가능 여부의 근거로
  사용하지 않는다.
- `place-yeongjin-beach`의 사용자 대표명은 원천 장소명인 `영진해변` / `Yeongjin Beach`로
  유지한다. MVP는 배우·작품만 검색하므로 장소 별칭을 런타임 검색 시드에 넣지 않는다.
  사용자는 장소 카드의 작품 관계·`sceneNote`에서 이곳이 `도깨비 방파제`로 알려진
  촬영지임을 확인한다.
- 주소는 원천 행을 사용했다. 위도·경도는 원천 좌표를 사용하되, 기존 조사에서 POI 또는
  촬영 구간 재확인이 필요하다고 기록한 라라무리·오크밸리 리조트는 좌표를
  비워 두었다. 빈 좌표는 0이나 임의 중심점으로 대체하지 않는다.
- 검토 기준일: 2026-08-08. 원천의 현재성 한계 때문에 주소·좌표는 실제 방문 전 재확인이
  필요하며, 사람 검토는 작품–장소 관계와 원천 행의 전사 정확성을 뜻한다.

### #51 장면 출연 배우 검토·자동 승격 (2026-08-09~10)

- `featuredActorIds`·`actorPresenceReviewed`는 **검증 출처에 배우명 또는 김고은의 배역명
  (지은탁·유미/김유미·오인주)이 명시된 경우에만** 기록했다. 회차 출연 사실(`reviewed`)을
  장면 등장으로 확대 해석하지 않는다.
- 등장 확정 8곳(ⓐ): 라라무리·발왕산 케이블카·전나무 숲길·월정사·엄마손막국수·
  스카이베이호텔·오크밸리·서울로7017 — 원문에 김고은(배역) 명시.
- 초기의 미등장 3곳(삼양목장·덕수궁 돌담길·경기전)은 김고은 단일 시드 시점에서
  "김고은 미등장"이었다. 공유·이민호 엔티티를 추가한 후에는 원천의 실명/배역명
  일치를 자동 재평가해 각 배우의 등장 확정으로 승격했다.
- 영진해변은 원천 CSV만으로는 장면·인물 미상이었으나, 한국관광공사 VISITKOREA의 장소
  상세와 한류 코스가 `은탁(김고은)`의 생일·메밀꽃 장면을 명시해 자동 A등급으로 승격했다.
  두 URL은 장면 맥락 출처로 보존하되, `은탁(김고은)` 연결을 직접 명시한 한류 코스 URL만
  `actorPresenceVerification.evidenceSourceUrls`에 기록한다. 판정 입력과 짧은 근거 문장은
  `actor-presence-evidence.json`에서 재현·감사한다.
- #26 참고 섹션의 9/3/1 현황과 원문 대조 결과가 일치함을 확인했다. 이 중 죽림동성당(ⓐ)은
  #61 확정(KTX 전용 범위)으로 런타임 시드에서 제외됐고, #72 부산 팩으로 벡스코·영화의전당
  (모두 원문에 김고은=정태을 장면 명시, ⓐ)이 추가됐고 영진해변을 승격해, 수록분은
  5명·10편 승격 후 전체 관계는 등장 확정(ⓐ) 41건·미등장 확정(ⓑ) 0건·
  미검토(ⓒ) 1건이다. 미검토 1건은 《미스터 션샤인》 문화공감수정으로, 작품 검색에는
  포함하지만 김태리 배우 검색에는 추측해 넣지 않는다.

### 박보검 1차 런타임 승격과 남원 팩 (2026-08-10)

- 심곡항·사천진해수욕장/항·손놀림 공방·광한루원은 #72에서 원천 장면 문구와 박보검
  실명/배역, KTX 앵커, 네이버지도 차량 접근시간(37·20·27·7분)을 검토했다.
- 광한루원은 남원역을 앵커로 쓴다. 서울↔남원 직결편은 코레일 공식
  `KTX 시간표(2026. 5. 15. 기준)` 전라선 시트에서 데모일의 요일 운행 조건을 적용해 수록했다.
  2026-09-01 시행 시간표는 데모일 이후라 사용하지 않았다.
  - https://www.korail.com/ticket/reserve/train-timetable
  - https://www.korail.com/file/cubedata/COMMON/jfile/202604/24/2026042419dbe8dce18380.xlsx
- 실서비스에서는 원천 수집 → 출처/참조/왕복 커버리지 자동 검증 → 버전 스냅샷 배포 순으로
  처리한다. 사람은 저신뢰, 출처 충돌, 역 미조인, 시간표 미확보 같은 실패 큐만 검토한다.
  사용자 요청마다 장소별 값을 다시 정하거나 모델 생성값을 즉시 일정에 쓰지 않는다.

### MVP 5명·10편 런타임 자동 승격 (2026-08-10)

- `runtime-promotion-batch.json`은 카탈로그 210곳 중 지원 역 축에 있는 18곳과 영문명·
  체류 유형·영문 장면 요약만 담는다. 원천 조인·배우 근거·좌표·접근시간은
  카탈로그에서 결정적으로 가져온다.
- `promote_runtime_catalog.py`는 확정 상태, 60분 이하 접근, 역 ID 조인, 데모 3일 서울 왕복
  시간표, 주소·좌표, 작품 관계, 배우 실명/배역명 일치를 자동 검증한다.
  하나라도 실패하면 부분 쓰기 없이 배치 전체를 중단한다.
- 정상 승격 실행은 `place-ranking-inputs.json`을 갱신한 뒤 `build_place_rankings.py`를 자동 호출한다.
  검증 완료된 작품–장소 관계만 OpenAI `text-embedding-3-small`로 점수화하고, 원천에서 검토된
  `sceneNote`를 노출 이유로 사용한다. 관계 미검토·설명 누락·참조 불일치만 중단해 사람이
  예외를 확인하며, 사용자 검색 시점에는 API를 호출하지 않는다.
- `build_place_rankings.py --check`와 CI는 런타임 관계 전부가 활성 랭킹을 정확히 하나씩
  가지는지 검사한다. 따라서 장소만 승격하고 관련성 정렬이 ID 폴백으로 남는 변경은 병합할 수 없다.
- 배우 실명이 공식 원천 문구에 직접 있으면 `rule_based` A등급으로 재생성하고,
  배역명만 있는 경우는 자동 확정하지 않는다. 구 서도역처럼 장소·작품·배역–배우를
  함께 명시한 공식 관광 근거를 별도로 찾은 예외만 `model_assisted`로 보강한다.
- 런타임 엄격 배우 후보는 김고은 20곳·박보검 10곳·공유 6곳·이민호 5곳·
  김태리 5곳이며, 작품 10편은 모두 최소 2곳 이상의 검증 관계를 가진다.

### `unverified` 유지

- 라라무리: 원천 CSV 시간과 현재 지도 표기가 달라 공식 영업시간을 확정하지 않았다.
- 엄마손막국수: 제3자 영업시간이 서로 충돌하고 현재 공식 근거가 없다.
- 스카이베이호텔 경포: 호텔 운영과 비투숙객의 촬영구역 내부 방문 가능시간은 별개다.
- 월정사: 한국관광공사에는 연중 24시간으로 표시되지만 월정사 공식 안내는
  `일출 이후~일몰 전 입장`으로 서로 충돌한다. 고정 시각으로 표현하지 않고 `unverified`로 둔다.
  - http://woljeongsa.org/bbs/content.php?co_id=105020
- 오크밸리 리조트: 리조트 전체가 아니라 실제 촬영구역과 비투숙객 이용 범위를 특정해야 한다.
- 벡스코: VISITKOREA 기준 연중무휴이나 운영시간이 행사별로 달라 확정 시각이 없다. 외관
  (극중 부산 CTX역)은 공공 공간에서 관람 가능해 후보를 유지한다.
  - https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=89982
- 영화의전당: VISITKOREA 기준 연중무휴·상영별 상이라 확정 시각이 없다. 야외 광장(두레광장)은
  공공 접근 가능해 후보를 유지한다.

## 공항버스 GatewayLeg (#58)

- 런타임은 `data/gateway-legs.json`만 읽는다. 공공 API와 예매 화면은 개발 중
  검증에만 사용하며, 좌석·교통상황·시간표를 런타임에 조회하지 않는다.
- 각 편은 `scheduleKind: observed_snapshot`, `recheckRequired: true`로 저장한다.

## 장소 체류시간 근거 (#84 MVP P1)

- `places.json`의 `stayMinutes`는 공식 권장 관람시간이 아니라 일정 가능성을 보수적으로
  계산하기 위한 서비스 기본 추정값이다. 공식 출처가 없는 값에 출처를 만들어 붙이지 않는다.
- 엔진은 기존과 동일하게 `stayMinutes`만 소비한다. `stayMetadata.basis`는 유형표로 산정한
  `category_default`와 공식 분 단위 코스를 확인한 `official_source`를 구분한다.
- Place 타입은 additive 하위 호환을 위해 optional이지만 배포 JSON 시드는 근거 메타가 없으면
  로드 단계에서 거부한다.
- `official_source`는 URL뿐 아니라 HTML 원문의 짧은 인용과 페이지 내 위치도 보관한다.
  주기 검증은 인용 소실·페이지 접근 실패를 알리기만 하며, 외부 페이지 변경으로 운영값을
  자동 갱신하지 않는다. 변경값·범위·일정 영향은 사람이 확인한 뒤 별도 변경으로 반영한다.
- 확정 유형표: 짧은 외관 방문 45분, 자연·산책 60분, 식음 60분, 역사·문화 60분,
  리조트 방문 90분, 대형 체험 120분. 장소별 분류와 정확한 ID는 `places.json`에 기록한다.
- 총 시간예산은 `(accessEstimate.minutes + max(20, ceil(accessEstimate.minutes × 0.5))) × 2
  + stayMinutes`로 계산한다. 도로 정체·식사·짐·실제 체류시간을 보장하지 않는다.

### 원천 CSV의 `장소타입`을 그대로 쓰지 않는 이유

원천(`data/raw/filming_locations_20260807.csv`, 15,034행)에 `장소타입` 컬럼이 있지만 어휘가
`restaurant`·`playground`·`cafe`·`stay`·`station`·`store` 중심이고, `playground`(5,987행)가
사실상 catch-all이다. 기존 14곳 중 10곳이 여기로 뭉쳐 있어 — 해변·사찰·숲길·목장·케이블카·
보행로·돌담길·전각·전시장·영화관이 전부 같은 값이다 — 아이콘 구분에 쓸 수 없다.

`stayMetadata.category`(#84 P0-4)도 다른 축이다. 그쪽은 **얼마나 머무는가**이고 유형은
**무엇인가**다. `brief_exterior` 하나에 호텔·고가 보행로·궁 담장길이, `culture_venue` 하나에
사찰·전각·전시컨벤션·영화관이 들어 있어, 체류시간 기준으로 아이콘을 고르면 호텔과 돌담길이
같은 그림이 된다.

    `places.json`에 재생성한다. 따라서 이후 재승격으로 유형이 사라지거나 임의 값이 들어오지 않는다.

### `heritage` 아이콘은 비워 둔다

월정사·경기전 등 한국 문화유산에 쓸 이모지가 유니코드에 없다. 형태가 가까운 것들은 전부 다른 문화의
기호다 — ⛩️는 일본 신사 도리이, 🏯는 일본 성, 🛕는 힌두 사원, 🏛️는 그리스 신전이다.
K-컬처 서비스에서 한국 사찰·전각에 그 기호를 붙일 수 없어, 틀린 아이콘을 넣는 대신
그라데이션 박스만 두고 글리프를 비운다. 유형 값 `heritage`는 시드에 남으므로 분류 사실과
근거는 유지되고, 화면에서만 글리프가 빈다.

이것은 **유형을 확인하지 못한 경우(기본 아이콘 📍)와 다른 상태**다. 둘을 같은 표시로
만들면 확인한 것과 확인하지 못한 것이 화면에서 구별되지 않는다.

## 항공

- `SAMPLE-ARRIVAL-001`과 `SAMPLE-DEPARTURE-001`은 회귀 테스트용 고정 입력이다.
- 실서비스의 실제 항공편 조회 결과가 아니며, 실호출 실패 시 폴백하는 데모 스냅샷이다.
