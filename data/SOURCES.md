# 데모 시드 출처와 한계

데모 기준일은 2026-08-12~14(KST)다. 이 문서는 `data/*.json`의 값을 실제보다
정확한 값처럼 보이지 않도록 원천, 검증 수준, 사용 범위를 기록한다.

## 데이터 사용 원칙

- 관광공사·공공데이터·지도 정보는 후보 발견용이다. 서로 충돌할 때 임의로 하나를
  정답으로 채택하지 않는다.
- 공식 근거로 일반 방문 가능시간을 확인한 경우에만 `hours` 또는 `always_open`을 쓴다.
- `unverified`는 **폐업·철거·방문 불가 확정이 아니다.** 영업시간이나 내부 입장 가능시간을
  확인하지 못했다는 뜻이다.
- 카페·호텔·리조트·성당처럼 영업하지 않는 날에도 공공도로에서 외관을 볼 수 있는 장소는
  검색·후보에서 유지한다. 내부 입장 또는 유료 체험이 필요한 일정만 운영시간을 하드 제약으로
  검사하는 것이 목표 동작이다.
- 현재 엔진은 `unverified`를 자동 일정에서 제외한다. 외관 방문 후보까지 추천하려면 후속으로
  `외관 방문 가능`과 `내부 입장 필요`를 데이터 스키마와 엔진에서 분리해야 한다. 그 전까지
  `unverified` 값을 거짓 운영시간으로 바꾸지 않는다.

## 촬영지 관계 원천

- 작품·촬영지 연결의 1차 원천: 한국문화정보원 촬영지 데이터
  - 공공데이터포털: https://www.data.go.kr/data/15111405/fileData.do
  - 로컬 원본: `data/raw/filming_locations_20260807.csv`
  - 내려받은 날: 2026-08-07
- 대표 배우·작품·후보 범위: GitHub 이슈 #1 및 #26. 나주영상테마파크를 운영 후보에서
  제거한 현재 시드는 13곳이다.
- 원천 CSV는 2022년 작성 값이 섞여 있으므로 현재 운영시간의 근거로 단독 사용하지 않는다.

### `unverified` 유지

- 라라무리: 원천 CSV 시간과 현재 지도 표기가 달라 공식 영업시간을 확정하지 않았다.
- 엄마손막국수: 제3자 영업시간이 서로 충돌하고 현재 공식 근거가 없다.
- 스카이베이호텔 경포: 호텔 운영과 비투숙객의 촬영구역 내부 방문 가능시간은 별개다.
- 월정사: 한국관광공사에는 연중 24시간으로 표시되지만 월정사 공식 안내는
  `일출 이후~일몰 전 입장`으로 서로 충돌한다. 고정 시각으로 표현하지 않고 `unverified`로 둔다.
  - http://woljeongsa.org/bbs/content.php?co_id=105020
- 오크밸리 리조트: 리조트 전체가 아니라 실제 촬영구역과 비투숙객 이용 범위를 특정해야 한다.
- 강촌레일파크: 원천 CSV 주소·좌표는 옛 강촌역(김유정 코스 도착지)을 가리키지만
  앞선 운영시간 조사는 경강 코스를 가리켰다. 실제 촬영 구간을 특정하기 전에는 코스명과
  운영시간을 확정하지 않는다.

### 운영 후보 제외

- 나주영상테마파크: 시설물 일부 철거 후 부지가 남도의병역사박물관으로 전환되었고
  나주시 촬영지 목록에서도 빠져 운영 후보에서 제거했다. 과거 데이터의 오류를 막는
  회귀 테스트가 필요하면 운영 시드와 분리한 전용 테스트 픽스처로 다시 만든다.
  - https://www.sisajournal.com/news/articleView.html?idxno=283056
  - https://news.ikbc.co.kr/article/view/kbc202508160011

## 역에서 촬영지까지

- `accessEstimate`는 교통편 추천값이 아니라 **일정 가능성 검증용 편도 시간 예산**이다.
- 사용자는 역에서 택시·버스·도보 등 원하는 수단을 선택한다. 서비스는 특정 수단을 보장하지 않는다.
- 카카오맵 자동차 길찾기의 역→장소 편도 실측값을 5분 단위로 올림했다(2026-08-08).
  이는 특정 교통수단 추천이 아니라 비교 가능한 기준값이며 실시간 교통을 보장하지 않는다.
  - 강릉역→영진해변 35분·25.8km → 35분. 원천 CSV 좌표가 북쪽으로 치우쳤을 가능성이 있어
    POI 좌표 재확인이 필요하다.
  - 강릉역→엄마손막국수 9분·2.5km → 10분
  - 강릉역→스카이베이호텔 경포 16분·6.8km → 20분
  - 진부역→월정사 19분·12.3km → 20분
  - 진부역→월정사 전나무 숲길 18분·11.8km → 20분
  - 진부역→삼양라운드힐 33분·23.4km → 35분
  - 진부역→발왕산 관광케이블카 19분·15.0km → 20분
  - 춘천역→옛 강촌역 26분·16.5km → 30분. 촬영 코스 확정 전 임시값이다.
  - 춘천역→죽림동성당 3분·1.1km → 보수 최소값 10분
  - 서울역→서울로7017 도보 0.3km → 보수 최소값 10분
  - 서울역→덕수궁 돌담길 차량 11분·도보 약 20분 → 도보 기준 20분
- 라라무리와 오크밸리는 원천 CSV 좌표가 도로 밖을 가리켜 현재 숫자가 검증된
  길찾기 결과가 아니다. POI 좌표 교체 후 재측정하며 그 전에는 임시 추정값으로만 사용한다.
- 스카이베이호텔 공식 안내의 버스 20~40분·택시 10~15분, 한국관광공사의
  진부역→월정사 택시 약 20분·버스 약 45분은 사용자가 수단을 고를 때 참고할 범위다.
  - https://skybay.co.kr/find_us
  - https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=225974
- 엔진은 `역 → 장소 → 역`에 같은 값을 적용하고 `max(20분, 접근시간의 50%)` 버퍼를
  편도마다 추가한다.
- UI에는 `역↔촬영지 예상 이동 여유`와 `추정` 라벨을 표시하고, 사용자가 이동 여유를
  바꾸면 열차 선택지와 이후 일정을 다시 검증하는 방향으로 확장한다.
