## filming_locations_20260807.csv

- 출처: 공공데이터포털 — 한국문화정보원 미디어콘텐츠 영상 촬영지 데이터
  (https://www.data.go.kr/data/15111405/fileData.do)
- 다운로드: 2026-08-07 (원본 인코딩 CP949 → UTF-8 변환본)
- 규모: 15,034행 / 컬럼: 연번, 미디어타입, 제목, 장소명, 장소타입, 장소설명, 영업시간, 브레이크타임, 휴무일, 주소, 위도, 경도, 전화번호, 최종작성일
- 용도: 배우-작품-촬영지 관계 추출과 시드 데이터의 단일 원천. 앱은 이 파일을 직접 읽지 않고
  `scripts/` 파이프라인이 생성한 JSON 시드만 사용한다.
- 주의: `영업시간` 필드는 전 행에 값이 있으나 **기재된 값이지 검증된 값이 아니다.**
  시드에 넣는 장소는 이슈 #5 정책에 따라 출처·검증일을 개별 확인한다.
- 알려진 정규화 이슈(이슈 #1 기록): 배우 관계는 장소설명 괄호 패턴 기반이라 오탐 존재
  (예: 블랙핑크 문서의 김고은 언급), '유미의 세포들'과 '유미의 세포들 2'는 제목 분리 →
  초기 플래너 시드에서는 통합 1작품 처리했으나, 현재 검색 Repository는 전체 카탈로그와 같은
  시즌 분리 계약을 사용한다.
- `scripts/actor_aggregation.py`의 출력은 **수동 검증 전 노이즈 포함 후보치**다(오탐·누락
  모두 가능). 증거 행 수(배우명 등장 행)와 작품 확장 집계(작품 전체 촬영지)를 분리해
  표시하며, 후보 간 상대 비교 용도로만 쓴다. **플래너 시드(작품 7편·촬영지 18곳)는 원문과
  이동·운영 조건을 별도 검증한 값**이다.

## catalog_access_review_20260809.json

- 위 원천에서 대표 배우 5명 관련 10개 작품을 추린 뒤, 지원 역 기준 OSRM 차량 접근시간과
  학교·사유지·폐업 가능성을 검토한 276개 후보 스냅샷이다. 공유·이민호는 기존 작품을
  재사용하고, 김태리는 《미스터 션샤인》·《스물다섯 스물하나》를 추가했다.
- 2026-08-09 최초 작성 후 2026-08-10 김태리 두 작품 후보 37개를 추가 검토했다. 파일명은
  최초 스냅샷 날짜를 유지하며 최신 검증일은 생성 카탈로그의 `verifiedAt`으로 기록한다.
- `data/filming-catalog-policy.json`의 제외·조건부·정정 정책과 함께
  `scripts/build_filming_catalog.py`가 검색용 `data/filming-catalog.json`을 생성한다.
- OSRM 시간은 대량 선별값이며 일정 편입 전 최신 지도와 운영·출입 조건 재확인이 필요하다.
- 검색 카탈로그 210곳과 일정 엔진의 `data/places.json` 18곳은 의도적으로 분리한다.
  5명·10편 엔티티는 실제 검색 Repository에 동기화하지만, 장소는 자동 승격 게이트를 통과한
  김고은 14곳과 박보검 4곳만 런타임에서 배치한다.
